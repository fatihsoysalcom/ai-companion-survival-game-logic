# AI Companion Survival Game Logic

This Python script simulates the core logic of an AI companion in a browser-based survival game. It demonstrates how an AI can assess a player's needs (health, hunger, thirst), provide recommendations, and attempt to assist by finding resources.

## Language

`python`

## How to Run

Save the code as `ai_survival_game.py` and run it from your terminal using `python ai_survival_game.py`.
